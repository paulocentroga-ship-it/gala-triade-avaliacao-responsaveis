# Gala Tríade 2026 — Avaliação de Responsáveis → Terapeutas PJ

Formulário anônimo (celular-first) para pais/mães/cuidadores avaliarem os terapeutas PJ da Tríade Espaço Terapêutico.

- Circuito 3, isolado dos circuitos PJ-entre-pares e CLT.
- Link personalizado por terapeuta: `?avaliado=Nome` (campo pré-preenchido e travado).
- Ficha: 4 blocos (A 40%, B 30%, C 20%, D 10%), 16 critérios, notas 1–5 + N/A.
- Nota final 0–100; na Gala: 70% pares + 30% responsáveis.
- Período avaliado: 01/01/2026 a 30/11/2026.
